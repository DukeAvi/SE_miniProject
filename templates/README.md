# Collaboration templates

These templates keep issues, pull requests, test evidence, decisions, and sprint reports consistent across concurrent work.

- `issue.md` is the general implementation issue format.
- `bug_report.md` records reproducible defects and regressions.
- `pull_request.md` is the review and merge handoff format.
- `test_evidence.md` records manual, automated, performance, security, and recovery results.
- `decision_record.md` resolves open product or architecture questions before implementation.
- `sprint_summary.md` captures sprint outcomes, evidence, deviations, and carry-over work.

GitHub-facing forms live in `.github/` and follow the same sections. Update both locations if the workflow changes.
