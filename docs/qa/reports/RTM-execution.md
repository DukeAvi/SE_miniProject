## Scope limits and decisions

Pass labels refer to actual automated execution within the reported environment. The browser walkthrough now covers actual Staff and Admin mutations and the previously missing donor onboarding flow. Five PostgreSQL locking cases passed; they are no longer unrun.

Actual human screen-reader/UAT acceptance, a complete month of observed availability, production offsite durability/restore timing and an external production TLS scan are not certified by automated tests. Existing owner classroom exceptions remain exceptions, not evaluator approval. Isolated TLS/process-recovery/encrypted-restore checks have CI evidence, and the original JMeter profile has measured p95 results. Comprehensive independent security certification is not claimed; implemented input/security tests passed.

Audit retention is verified at application level; physical monthly partitions and a dedicated database privilege split are documented design deviations. STP security is section 5.1 and compatibility section 5.4, with unchanged IDs. Source diagrams and the original design basis are retained in final SRS/SAD PDFs.
